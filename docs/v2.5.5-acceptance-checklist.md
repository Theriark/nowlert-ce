# Nowlert v2.5.5 acceptance checklist

## Automated

- [ ] Python compilation passes.
- [ ] JavaScript syntax validation passes.
- [ ] YAML and production Compose validation pass.
- [ ] Documentation and packaged-icon validation pass.
- [ ] Focused v2.5.5 tests pass.
- [ ] Complete pytest suite passes.
- [ ] Release-candidate image builds with a commit-pinned Teams icon base URL.
- [ ] Image reports version 2.5.5 and schema 9.

## Microsoft Teams

- [ ] Generic Nowlert test payload is at most 28 KiB.
- [ ] HPE iLO test payload is at most 28 KiB.
- [ ] Generic test displays the Nowlert image.
- [ ] HPE iLO test displays the HPE iLO image.
- [ ] Source images use public HTTPS URLs, not Base64 data URIs.
- [ ] An oversized synthetic payload is rejected before an HTTP request.
- [ ] The safe error code is `teams_payload_too_large`.
- [ ] HTTP 202 is displayed as accepted, not delivered.
- [ ] WebUI asks the operator to confirm the card appeared in the channel.
- [ ] Real generic and HPE iLO tests arrive in the configured Teams channel.

## Discord regression

- [ ] Discord still uploads the exact packaged root or padded source image.
- [ ] Discord Components V2 still uses `attachment://filename`.
- [ ] Discord response verification still fails closed for a missing image.
- [ ] One real Discord destination test displays its source image.

## Production

- [ ] Pre-deployment config, state, and secrets backup exists.
- [ ] Production reports version 2.5.5 and schema 9.
- [ ] Existing destinations, routes, users, tokens, settings, and history remain.
- [ ] Restart count remains zero.
- [ ] No startup traceback or database integrity error appears.
- [ ] v2.5.4 rollback command and backup path are recorded.
