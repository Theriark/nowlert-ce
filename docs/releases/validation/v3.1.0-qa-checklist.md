# Nowlert CE v3.1.0 QA checklist

This checklist mirrors the v3.1.0 QA handoff tracked in Jira as **NCE-20** and
covers the changes prepared in **NCE-5 through NCE-19**.

## Candidate baseline

- Version: **3.1.0**
- Development source commit:
  `7ca98d260f75e14af789a426a8a1797f23b7a70a`
- Validated Development image:
  `ghcr.io/theriark/nowlert-ce@sha256:53ff043e3a6adb77301589ea7c03a52ccf3dca6140efa3209acb64b9ecadca5e`
- Local automated suite before documentation pass: **1023 passed**
- Development CI, built-image verification, Dokploy health gate, and smoke:
  **passed**

Hard-refresh the browser before visual QA so older WebUI assets are not reused.
Do not capture or publish secrets, webhook URLs, tokens, passwords, private
email addresses, or other credentials.

## Ticket validation

### NCE-5 — Destination title/message limits

- Verify supported Title and Message maximums are accepted.
- Attempt to exceed the limits and verify clear client-side validation.
- Verify Preview and Send do not produce an unclear server error from excessive
  input.

### NCE-6 — Long destination title layout

- Test a long destination title in create/edit views and destination cards.
- Confirm the title never overlaps controls or adjacent cards.

### NCE-7 — Configured webhook presentation

- Edit an existing webhook-based destination.
- Confirm Nowlert indicates that a webhook is already configured without
  exposing the stored secret value.
- Save without replacement and confirm the destination remains functional.

### NCE-8 / NCE-9 — Restart Nowlert

- Open the top-right Restart Nowlert action, enter a QA reason, and restart.
- Verify the application returns healthy at version 3.1.0.
- Confirm the restart-policy warning text is no longer shown.

### NCE-10 — Routes pagination

- Use enough routes to exceed one page.
- Verify forward/back/page controls do not duplicate or skip routes.
- Recheck pagination after edits/filtering.

### NCE-11 — Route bulk event selection

- Edit a route with selected severities/statuses.
- Test Select All and Clear for both severities and statuses.
- Save and reopen to confirm persistence.

### NCE-12 — Delivery History pagination

- Navigate multiple pages of delivery records.
- Verify search/filtering and pagination work together without duplicate or
  missing rows.

### NCE-13 — Audit Log pagination

- Navigate older audit records through pagination.
- Verify filters/sorting continue to work and the previous effective 500-entry
  browsing limitation is removed when a sufficiently large dataset is present.

### NCE-14 — Username limit

- Verify a 64-character username is accepted.
- Verify more than 64 characters cannot be submitted and produces clear
  validation.

### NCE-15 — Regional settings

- Verify expanded language and timezone choices.
- Save a non-default QA value and confirm it persists after refresh/reopen.

### NCE-16 — Backup and restore

- Test backup destination connectivity/write access.
- Create a manual backup and verify the generated snapshot is accessible and
  successful.
- Restore a known-good QA backup and verify the expected configuration/state.
- Test at least one safe failure path, such as unavailable destination or invalid
  restore input, and confirm the current state remains intact.

### NCE-17 — Official Nowlert branding

- Verify the approved owl on login, sidebar, favicon/application icon, and
  branded empty states.
- Confirm no legacy application icon remains after a hard refresh.
- Send a new generic Nowlert Discord notification and confirm the approved owl
  and `Theriark • Nowlert v3.1.0` footer.

### NCE-18 — Profile picture action

- Verify Save Picture is not offered/enabled before selecting a new image.
- Select a valid image and verify the save action becomes available and works.

### NCE-19 — Integration Settings cancel/close behavior

Using an integration such as Zabbix:

- With no edits, Cancel, X, and Escape close without saving or a success toast.
- With edits, Cancel/X/Escape display **Discard unsaved changes?**.
- Declining discard keeps the editor open with changes intact.
- Confirming discard closes without saving.
- Save settings saves directly with one success toast and persists after reopen.

## Cross-cutting v3.1.0 UI checks

- Dashboard Delivery History and Recent Activity align at the same top edge.
- Top Sources and Top Destinations branded empty states render correctly when
  no ranking data exists.
- Destinations render directly as the card grid without an unnecessary second
  list-style panel/header.
- Delivery History retains its Delivery attempts content header.
- Sources, Routes, Audit Log, Users, Settings, Updates, Inputs, Backups, Data
  tools, and Account Security show contextual descriptions.
- Browser Back and Forward navigation traverses Nowlert sections before leaving
  the application.
- Populated Dashboard, Routing Flow, Destinations, Routes, and Delivery History
  render correctly with existing data.
- Perform one safe end-to-end firing/resolved notification and verify expected
  delivery/history behavior.
