# Nowlert CE v3.1.1 QA checklist

Use this checklist against the exact release candidate that will be promoted.
Do not validate one source commit and release a different source/image.

## Candidate identity

- [ ] `development` source SHA recorded
- [ ] Development Image run ID recorded
- [ ] immutable GHCR digest recorded
- [ ] `/api/health` reports `3.1.1`
- [ ] `src/version.py`, README, Docker Hub README, `.env.example`, Compose default,
      release notes, and screenshots all describe v3.1.1
- [ ] current documentation validator passes
- [ ] full automated test suite passes

## Basic platform

- [ ] clean browser login works
- [ ] existing administrator login works after upgrade
- [ ] sidebar profile chip displays **Admin** for administrator accounts
- [ ] regular account displays **User**
- [ ] Overview loads without resource-wide failure
- [ ] health checks return expected results
- [ ] restart control remains functional and audited

## Users — NCE-30 / NCE-33

- [ ] administrator can create a disposable regular user
- [ ] administrator can disable/re-enable that user
- [ ] administrator can reset that user's password
- [ ] administrator sees a destructive delete action
- [ ] delete requires explicit confirmation
- [ ] deleting the disposable user succeeds
- [ ] deleted user can no longer authenticate
- [ ] successful deletion appears in Audit Log
- [ ] current administrator cannot delete its own active account
- [ ] platform cannot be left without an enabled administrator

## Backups — NCE-31

- [ ] create a private state snapshot
- [ ] snapshot appears in Backups/Data tools
- [ ] selected snapshot has a delete action
- [ ] delete requires explicit confirmation
- [ ] deleting one snapshot removes only that snapshot
- [ ] remaining snapshots are unchanged
- [ ] backup deletion is visible in Audit Log
- [ ] create/restore workflow remains available and separate from deletion

## Delivery History — NCE-34 / NCE-35

- [ ] delivery rows do not show duplicate Delivered/status badges
- [ ] empty placeholder badge decoration is absent
- [ ] First / Previous / Next / Last work
- [ ] `Page [n] of N - X items` contains the editable page input
- [ ] pressing Enter in the page input navigates directly
- [ ] no separate Go button is present
- [ ] Top is on the left side of the footer row
- [ ] Entries selector is aligned on the right side of the same row
- [ ] selected page size persists
- [ ] entering Delivery History starts at the top
- [ ] header Bottom shortcut scrolls to the controls
- [ ] page changes preserve the approved scroll behavior

## Audit Log — NCE-35

- [ ] First / Previous / Next / Last work
- [ ] editable page input is embedded in `Page [n] of N - X items`
- [ ] Enter performs direct page navigation
- [ ] no separate Go button is present
- [ ] Top and Entries share the bottom control row
- [ ] page-size persistence works
- [ ] Bottom shortcut and page-change scrolling work

## Routes — NCE-36 / NCE-37 / NCE-38 / NCE-39

- [ ] route editor does not display Excluded Severities
- [ ] route editor does not display Excluded Statuses
- [ ] Included Severities uses native selected-option highlight
- [ ] Included Statuses uses native selected-option highlight
- [ ] unselected items do not use custom red styling
- [ ] normal click adds one severity/status without clearing previous selections
- [ ] clicking a selected value again removes only that value
- [ ] native range/drag selection remains usable
- [ ] values shown are appropriate for the selected integration/input
- [ ] save a route with all severities + partial statuses and verify both criteria
      are displayed on the Routes page
- [ ] save a route with partial severities + all statuses and verify both criteria
      are displayed on the Routes page
- [ ] dedicated route still wins before fallback
- [ ] fallback runs only when no dedicated route matches
- [ ] duplicate delivery to the same destination remains suppressed

## Destinations and delivery

- [ ] destination list loads
- [ ] destination credentials remain write-only
- [ ] preview does not expose secrets
- [ ] a safe destination test produces the expected result
- [ ] Delivery History records safe outcome metadata
- [ ] no response body/credential value appears in Delivery History or Audit Log

## Configuration/state compatibility

- [ ] schema remains 9
- [ ] `platform.configuration_model` is `platform_database_v1`
- [ ] `/nowlert/state` is writable by the configured UID/GID
- [ ] legacy WebUI-managed YAML sections are not required
- [ ] existing v3.1.0 state starts without migration failure
- [ ] matched pre-upgrade backup is retained for rollback

## Immutable promotion — NCE-32

### Development

- [ ] candidate is integrated into `development`
- [ ] CI passes on that exact SHA
- [ ] Development Image builds one immutable digest
- [ ] Development runs that exact digest
- [ ] Development desired-state evidence references that SHA/digest

### Stage

- [ ] Promote CE to Stage is launched from `development`
- [ ] Stage input `source_commit` equals current `development`
- [ ] Stage input `ce_image` equals the Development immutable digest
- [ ] full notification-silent gate passes
- [ ] passive Stage smoke passes
- [ ] Stage desired-state ledger is written
- [ ] `stage` advances to the exact source SHA
- [ ] no rebuild occurs

### Main

- [ ] compare proves `stage` is fast-forward-safe from `main`
- [ ] `main` is fast-forwarded without force
- [ ] `main == stage == source_commit`

### Production Reference

- [ ] workflow is launched from `main`
- [ ] `source_commit == main == stage`
- [ ] exact image is confirmed as Stage-approved
- [ ] Stage ledger/evidence validation passes
- [ ] full notification-silent Production Reference gate passes
- [ ] Production Reference runs the same immutable digest
- [ ] passive Production Reference smoke passes
- [ ] Production Reference ledger is written
- [ ] no rebuild occurs

### Release finalization

- [ ] `src/version.py` is `3.1.1`
- [ ] Finalize CE Release is launched from `main`
- [ ] source commit equals current `main`
- [ ] live Production Reference digest equals `final_image`
- [ ] Development, Stage, and Production Reference run IDs are supplied
- [ ] annotated `v3.1.1` tag is created on the exact source commit
- [ ] GitHub Release is created successfully
- [ ] release evidence artifact/ledger record is produced

### Stable aliases / public production

- [ ] Docker Release Aliases is launched from `main`
- [ ] `ghcr.io/theriark/nowlert-ce:3.1.1` resolves to approved digest
- [ ] `ghcr.io/theriark/nowlert-ce:latest` resolves to approved digest
- [ ] `docker.io/theriark/nowlert-ce:3.1.1` resolves to approved digest
- [ ] `docker.io/theriark/nowlert-ce:latest` resolves to approved digest
- [ ] alias publication reports `Image rebuild performed: no`
