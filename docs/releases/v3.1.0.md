# Nowlert v3.1.0 release notes

Nowlert v3.1.0 refreshes the Community Edition WebUI with the approved Nowlert
visual identity while retaining the QA and reliability corrections prepared
for the release.

## WebUI and branding

- Adopt the approved Amber Accent dark WebUI direction.
- Use the Nowlert charcoal, warm beige, soft taupe, amber-gold and alert-gold
  brand palette throughout the management interface.
- Replace the legacy Nowlert application icon with the approved owl brandmark.
- Refine navigation, cards, forms, tables, dialogs, login/bootstrap views,
  focus states, spacing and responsive presentation.
- Rename the landing view from Overview to Dashboard for clearer product
  language.
- Keep visual changes on top of the existing semantic HTML and same-origin
  browser security model; no decorative fake controls are introduced.

- Align Delivery History and Recent Activity, and add explanatory headers to Destinations and Delivery History.

## QA fixes included

- Make WebUI menu navigation participate in browser Back and Forward history.

- Add consistent contextual descriptions across the management pages.
- Add a content header strip to Delivery History while preserving Destinations as a card grid.
- Add branded empty states for Top Sources and Top Destinations.

- Prevent Integration Settings from saving when Cancel, Close, or Escape is used, and warn before discarding unsaved edits.

- Fix the Restart Nowlert action so the process exits cleanly and the container
  restart policy can restart it.
- Remove the misleading container restart-policy warning.
- Improve destination validation, long-title handling and configured webhook
  presentation without exposing stored credentials.
- Add Routes, Delivery History and Audit Log pagination improvements.
- Add Select All and Clear actions for route severities and statuses.
- Enforce the 64-character username limit.
- Expand regional language and timezone options.
- Hide Save Picture until a new image is selected.
- Fix the VM-09 development image bootstrap configuration packaging.

- Version the approved owl asset across the WebUI and Discord, and gate Dokploy smoke tests on the expected running version.

## Compatibility

- Database schema remains 9.
- Configuration model remains `platform_database_v1`.
- Existing `NOWLERT_*` environment variables, API contracts, backup formats and
  `/nowlert` container paths are retained.
- No database migration is required from v3.0.0.

## Release validation

approved screenshots for the README, run the full automated test suite, then
