# Nowlert v3.0.0 acceptance checklist

## Repository and publication

- [ ] Repository is `Theriark/nowlert`.
- [ ] Default branch and branch protections are correct.
- [ ] Release workflow refuses publication from another repository.
- [ ] No `v3.0.0` tag exists before final approval.
- [ ] Docker Hub can publish `theriark/nowlert`.
- [ ] GitHub Actions can publish `ghcr.io/theriark/nowlert`.

## Product identity

- [ ] WebUI displays Nowlert and Theriark.
- [ ] Health endpoints report `3.0.0`.
- [ ] OCI title is Nowlert.
- [ ] OCI vendor is Theriark.
- [ ] OCI source is `https://github.com/Theriark/nowlert`.
- [ ] WebUI update checks use `Theriark/nowlert`.
- [ ] Public Teams icon URLs use `Theriark/nowlert`.

## Runtime identity

- [ ] `NOWLERT_*` variables work.
- [ ] `X-Nowlert-Token` works.
- [ ] `nowlert.*` schemas are used.
- [ ] Nowlert cookies are used.
- [ ] `nowlert.db` state is accepted.
- [ ] Internal `/nowlert` mounts are valid.
- [ ] Existing backups remain restorable.
- [ ] Product asset URLs use the Nowlert identity.

## Migration

- [ ] Schema remains 9.
- [ ] Configuration model remains `platform_database_v1`.
- [ ] Administrator login succeeds.
- [ ] Destination, route, and secret counts are preserved.
- [ ] No duplicate destination or route names exist.
- [ ] No orphan routes exist.
- [ ] Wildcard routes retain distinct generic, Redfish, and home-lab names.

## Runtime and delivery

- [ ] SMTP and HTTP listeners become ready.
- [ ] Discord test delivery succeeds.
- [ ] Microsoft Teams real delivery is validated.
- [ ] Disabled placeholders remain disabled.
- [ ] Delivery History and Audit Log record correct results.
- [ ] Restart returns Nowlert to service.

## Security and rollback

- [ ] Container uses the configured non-root UID/GID.
- [ ] Root filesystem is read-only.
- [ ] Capabilities are dropped.
- [ ] `no-new-privileges` is active.
- [ ] Secrets are absent from logs and CI output.
- [ ] Matched pre-upgrade backup exists.
- [ ] Previous v2.5.5 image remains available.
- [ ] Stopped `nowlert-dev` remains until final acceptance.
- [ ] Runtime backups remain retained.
