# Nowlert CE v3.1.3 QA checklist

This checklist is the release acceptance record for Nowlert CE v3.1.3.

## Release identity

- [ ] `src/version.py` reports `VERSION = "3.1.3"`.
- [ ] `.env.example` defaults to `theriark/nowlert-ce:3.1.3`.
- [ ] `compose.production.yaml` defaults to `theriark/nowlert-ce:3.1.3`.
- [ ] README stable badge and Current Stable Release report `v3.1.3`.
- [ ] Docker Hub text reports `v3.1.3` and image `theriark/nowlert-ce:3.1.3`.
- [ ] `docs/releases/v3.1.3.md` and this checklist are present on the source commit.
- [ ] `v3.1.3` does not already exist before finalization.

## Documentation release scope

- [ ] `docs/guides/README.md` lists the consolidated practical guide set.
- [ ] Xen Orchestra → Discord guide is present.
- [ ] Xen Orchestra → Microsoft Teams guide is present.
- [ ] Direct homelab SMTP guide is present.
- [ ] Dell iDRAC / Redfish guide is present.
- [ ] Zabbix → Event API → Discord guide is present.
- [ ] `docs/integrations/README.md` exists and resolves the integration-index path without moving historical guide files.
- [ ] Current guide examples use the WebUI/database-authoritative destination/route/token model and do not reintroduce legacy WebUI-managed YAML resources.

## Automated validation

- [ ] CI passes on the version-complete `development` source commit.
- [ ] `python tools/validate_current_documentation.py` passes.
- [ ] Full `python -m pytest -q` passes inside the notification-silent Stage gate.
- [ ] Development image health reports exactly `3.1.3` before Stage promotion.

## Immutable Development candidate

Record:

```text
SOURCE_COMMIT=
FINAL_IMAGE=ghcr.io/theriark/nowlert-ce@sha256:
DEVELOPMENT_RUN_ID=
```

- [ ] `SOURCE_COMMIT` equals current `development` when Stage is dispatched.
- [ ] `FINAL_IMAGE` is an immutable GHCR digest, not a mutable tag.
- [ ] Development run completed successfully for that exact source SHA.

## Stage

Record:

```text
STAGE_PROMOTION_RUN_ID=
```

- [ ] Stage full gate passes with external notification delivery disabled.
- [ ] Exact Development digest is deployed; no image rebuild is performed.
- [ ] `/api/health` reports `3.1.3`.
- [ ] Passive Stage promotion smoke passes.
- [ ] Stage desired-state ledger is recorded.
- [ ] `stage` advances to `SOURCE_COMMIT` using fast-forward-only ref movement.
- [ ] Stage ref propagation verification completes successfully.

## Main and Production Reference

- [ ] `main` is fast-forwarded to the Stage-approved source with no force.
- [ ] `main == stage == SOURCE_COMMIT` before Production Reference dispatch.

Record:

```text
PRODUCTION_REFERENCE_RUN_ID=
```

- [ ] Production Reference validates Stage run and ledger evidence.
- [ ] Full notification-silent gate passes again.
- [ ] Exact same immutable digest is deployed; no rebuild is performed.
- [ ] Production Reference `/api/health` reports `3.1.3`.
- [ ] Passive Production Reference smoke passes.
- [ ] Production Reference desired-state ledger is recorded.

## Release finalization

- [ ] Finalizer is dispatched from `main` with `version=v3.1.3`.
- [ ] Finalizer proves `v3.1.3` equals `v` + source `VERSION` before publication.
- [ ] Finalizer proves the v3.1.3 release notes and QA checklist exist on source.
- [ ] Development, Stage, and Production Reference evidence all refer to the same source SHA and immutable image digest.
- [ ] Annotated `v3.1.3` tag points to `SOURCE_COMMIT`.
- [ ] GitHub Release `v3.1.3` is created with release evidence attached.
